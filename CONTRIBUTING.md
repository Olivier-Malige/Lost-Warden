# Contributing to Lost Warden

Thanks for your interest in the project!

## Code

Code contributions should be submitted via pull requests and are intended to be distributed under the project's existing MIT License. Only contribute code you have the right to license on those terms; identify third-party code and its license.

Contributors retain their own copyright unless agreed otherwise. Contributions are not automatically assigned to the maintainer. Please describe changes and test the relevant Godot scenes when possible.

## Art, sound and story

Before submitting sprites, illustrations, UI art, music, sound effects, lore or other creative assets, discuss provenance, ownership, AI generation tools and proposed licensing with the maintainer. Do not assume that the code's MIT License or the asset policy automatically covers your contribution. Written permission or an asset-specific license may be needed.

Never submit third-party copyrighted material without adequate redistribution rights.
